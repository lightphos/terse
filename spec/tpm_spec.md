# tpm — Terse Package Manager (spec draft)

**Status:** Deferred · design only  
**Language:** Prefer Terse when host surface is enough; Python prototype acceptable  
**Relation to compiler:** `tpm` only installs files; `use` resolution stays path-based

---

## 1. Goals

- Install optional packages into a project’s `lib/` (or a cache that is visible to `use`)
- Record versions and integrity in a lockfile
- Keep the compiler simple: **no registry logic inside `tersec` / `tc.te`**
- Stay terse: few commands, predictable layout, no required central host at first

## 2. Non-goals (for now)

- Full dependency solver (SemVer ranges across deep trees)
- Replacing `use` with registry URLs
- Publishing workflow UI / accounts (can be added later)
- Native bootstrap of `tpm` before HTTP + hash exist on the host

---

## 3. Separation of concerns

| Component | Responsibility |
|-----------|----------------|
| **`tersec` / `tc`** | Resolve `use math` → `lib/math.te` (or `lib/math/…`) and compile |
| **`tpm`** | Fetch, version, verify, write files under `lib/` + lockfile |
| **Registry / index** | Optional later; list of package names → download URLs |

```text
tpm add math@0.2   →  writes lib/math.te (+ lock entry)
use math           →  compiler opens lib/math.te
```

---

## 4. On-disk layout

### 4.1 Single-file package (preferred for small libs)

```text
lib/math.te
```

```terse
// use math
pub fn abs(x: i64) -> i64 { … }
```

### 4.2 Multi-file package

```text
lib/math/
  terse.pkg          # manifest
  math.te            # entry (or src/math.te)
  …
```

### 4.3 Manifest (`terse.pkg`)

Human-editable, minimal key-value or simple structured text (JSON optional later):

```text
name: math
version: 0.2.0
entry: math.te
# optional:
# description: Integer helpers
# deps:
#   - otherlib 0.1.0
```

Rules:

- `name` must match the `use` path leaf (`use math` → name `math`)
- `entry` is relative to the package directory
- Missing `terse.pkg` on a single-file `lib/math.te` is allowed (version only in lockfile)

### 4.4 Project lockfile

```text
terse.lock
```

Example:

```text
# generated by tpm — do not edit by hand unless you know why
math 0.2.0 sha256=… source=https://example.com/math-0.2.0.te
http 0.1.0 sha256=… source=git+https://…#v0.1.0
```

One line per direct (and later transitive) package.

### 4.5 Cache (optional)

```text
~/.terse/pkg/<name>/<version>/…
```

`tpm` may download into the cache, then copy or link into the project `lib/`.

Env:

| Variable | Meaning |
|----------|---------|
| `TERSE_HOME` | Default `~/.terse` |
| `TERSE_PKG_CACHE` | Override package cache dir |
| `TERSE_LIB` | Compiler lib object dir (existing); not the same as source `lib/` |

---

## 5. Commands (CLI)

```text
tpm init                 # create empty terse.lock (and optional terse.pkg for an app)
tpm add <spec>           # install into lib/ and lock
tpm remove <name>        # remove from lib/ and lock
tpm update [name]        # refresh within allowed versions
tpm list                 # show locked packages
tpm verify               # check lock hashes against files on disk
tpm help
```

### Spec forms for `tpm add`

| Spec | Meaning |
|------|---------|
| `math` | Latest known (index or default channel) |
| `math@0.2.0` | Exact version |
| `math@0.2` | Latest matching 0.2.x (when ranges exist) |
| `./vendor/math` | Local path |
| `https://…/math.te` | Direct URL (single file) |
| `git+https://…#tag` | Git (phase 2; may shell out) |

---

## 6. Compiler interaction

No change required beyond current resolution (SPEC §5):

1. Importer directory  
2. Parallel `tst/` → `src/`  
3. **`lib/<path>.te`**  
4. **`src/<path>.te`**  
5. Fallbacks  

`tpm` must install so that step 3 finds the package.

Optional later:

- Extra search path env `TERSE_PATH=lib:~/…`  
- Not required for v0

---

## 7. Versioning

- **Format:** SemVer `MAJOR.MINOR.PATCH` recommended  
- **Lockfile** always stores exact versions  
- **v0 solver:** exact versions only (no range resolution)  
- **v1 solver:** simple caret/tilde optional; refuse complex conflicts rather than clever merges  

---

## 8. Integrity

- Record **SHA-256** (or SHA-512) of the installed entry file(s) in `terse.lock`  
- `tpm verify` fails if on-disk content does not match  
- Downloads must verify hash when the index provides one  

Requires a host hash API or shell-out until Terse has `std.crypto` / similar.

---

## 9. Phased delivery

### Phase 0 — Spec only (this document)

- Layout + commands agreed  
- No implementation

### Phase 1 — Python prototype (`tpm` script next to `tersec.py`)

- `add` / `remove` / `list` from **local path** and **URL** (curl/wget)  
- Write `lib/` + `terse.lock` with hashes  
- No public registry

### Phase 2 — Index file

- Fixed URL to a static `index.json` (name → versions → url + hash)  
- `tpm add math@0.2.0` resolves via index

### Phase 3 — Terse implementation

When host has:

- Reliable file IO (`std.io`)  
- CLI args  
- HTTP get (or documented shell-out)  
- Hash helper  

Port logic from the Python prototype to `src/tpm.te` / `lib` tool.

### Phase 4 — Registry (optional)

- Publish API, auth, moderation  
- Only when many external packages exist  

---

## 10. Host surface gaps (for a Terse-written tpm)

| Need | Notes |
|------|--------|
| HTTP client | `http.get(url) -> str` or bytes |
| SHA-256 | `hash.sha256(bytes/str) -> str` |
| CLI argv | Already partial (`arg`) |
| mkdir / list dir | May need small FS expand beyond in/out |
| Exit codes | Non-zero on failure |

Until these exist, implement Phase 1 in Python without blocking language work.

---

## 11. Example workflow

```bash
# project root
tpm init
tpm add math@0.2.0
# → lib/math.te
# → terse.lock updated

# code
# use math
# go { pr(math.fact(5)) }

python3 compiler/tersec.py build app.te -o out/app
tpm verify
```

---

## 12. Relation to optional packages today

| Today | With tpm later |
|-------|----------------|
| Hand-maintain `lib/math.te` in the Terse repo | Same files; `tpm` can install copies into other projects |
| No version field required | Lockfile records version + hash |
| No registry | Path / URL / git first; registry last |

Frozen **`std.*`** (`std.str`, `std.io`, `std.tst`) stays **out of tpm** unless explicitly decided otherwise. Optional packages (`math`, `http`, …) are the target.

---

## 13. Open questions

1. Single-file vs always-directory packages for published artifacts?  
2. Should `tpm add` default to project `lib/` or `~/.terse/pkg` + link?  
3. Transitive deps in v0 or only direct deps?  
4. Index format: JSON vs terse-friendly text?  

Defaults until decided: **single-file OK**, install into **project `lib/`**, **direct deps only**, **JSON index** for Phase 2.

---

## 14. Summary

**tpm** = install + version + verify into `lib/`.  
**Compiler** = `use` path resolution only.  
**Registry** = optional Phase 4.  

Implement only when package sharing outside the main tree becomes routine; until then this file is the contract.
